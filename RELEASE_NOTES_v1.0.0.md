# CD2 Matrix Studio v1.0.0

First public release of **CD2 Matrix Studio**, an unofficial LED matrix editor for the Flydigi Charging Dock 2 Pro.

## Highlights

- Direct control of the dock's 162 RGB LEDs
- Static drawings and multi-frame animations
- Confirmed 10 ms and 40 ms dock animation timing
- Frame thumbnails and drag-and-drop ordering
- Copy/paste and duplicate frames
- Draw, erase, fill and eyedropper tools
- Mirror drawing mode
- Recent colors
- English and Russian UI
- Built-in user guide
- Portable EXE and Windows installer
- Legacy JSON import
- `.cd2proj` project format

## Compatibility

Tested with Flydigi Charging Dock 2 Pro:

- VID `37D7`
- PID `6001`

## Important

Fully close Flydigi Space Station before sending data to the dock.
